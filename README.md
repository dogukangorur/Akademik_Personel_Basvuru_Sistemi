# 🎓 Akademik Personel Başvuru Sistemi (APBS)

Akademik Personel Başvuru Sistemi (APBS), Kocaeli Üniversitesi Akademik Atama Yönergesi'ne uygun olarak geliştirilen, akademik kadro başvurularını dijital ortamda toplayan, değerlendiren ve jüri süreçlerini yöneten bir web uygulamasıdır.

## 📌 Proje Amacı

Akademik başvuru süreçlerinde yaşanan belge kayıpları, yanlış değerlendirmeler ve zaman kaybı gibi sorunları ortadan kaldırarak süreci **şeffaf**, **güvenli** ve **hızlı** hale getirmeyi amaçlamaktadır.

## 🧩 Kullanılan Teknolojiler

- **Frontend:** React.js + Tailwind CSS (responsive ve kullanıcı dostu arayüz)
- **Backend:** Node.js (Express.js RESTful API)
- **Veritabanı:** MySQL
- **API Entegrasyonları:** e-Devlet & Nüfus Müdürlüğü doğrulama servisleri
- **Bildirimler:** Nodemailer

## 🔐 Ana Özellikler

- Kullanıcı girişi ve yetkilendirme. 
- Personel Daire Başkanlığı tarafından ilan 
oluşturulması. 
- Adayların başvuru yapması ve belgeleri 
yuklemesi. 
- Jüri üyelerinin değerlendirme yapması. 
- Otomatik puan hesaplama modülü. 
- E-posta ve sistem içi bildirim entegrasyonu. 
- PDF formatında belge oluşturma. 
- Nufus Müdürlüğü  ve e-Devlet APİ entegrasyonu.

# 🎓 Academic Personnel Application System (APAS)

The Academic Personnel Application System (APAS) is a web-based application developed in accordance with Kocaeli University's Academic Appointment Directive. It facilitates the digital collection, evaluation, and jury management of academic job applications.

## 📌 Project Purpose

The project aims to eliminate issues such as document loss, incorrect evaluations, and time inefficiencies commonly encountered in academic application processes, ensuring a **transparent**, **secure**, and **fast** system.

## 🧩 Technologies Used

- **Frontend:** React.js + Tailwind CSS (responsive and user-friendly interface)
- **Backend:** Node.js (Express.js RESTful API)
- **Database:** MySQL
- **API Integrations:** e-Government & Population Directorate identity verification services
- **Notifications:** Nodemailer

## 🔐 Key Features

- User authentication and role-based authorization  
- Job postings created by the Personnel Department  
- Application submission and document uploads by candidates  
- Evaluation of applications by jury members  
- Automatic score calculation module  
- Integration of email and in-system notification services  
- PDF document generation  
- Integration with Population Directorate and e-Government APIs
